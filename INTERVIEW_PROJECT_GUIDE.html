💻 3. Frontend Architecture Deep-Dive

A. Voice AI Engine

Browser ki native window.speechSynthesis aur webkitSpeechRecognition use ki gayi hai jisse zero external latency aur zero API billing hoti hai. Autoplay audio context unlock mechanism lagaya gaya hai.

B. AI WebCam Gaze & Proctoring System

Canvas Optical Center-of-Mass luminance algorithm se head turn track hota hai. 25° offset allow hai aur keyboard par dekh kar code type karna explicitly permitted hai. Dim-light resilience ke liye multi-tier skin luminance aur 3.5s position grace period diya gaya hai.

⚙️ 4. Backend & Database Architecture

A. FastAPI Framework

FastAPI ASGI asynchronous concurrency support karta hai, automatic request validation aur high-speed performance provide karta hai.

B. SQLite Database in WAL Mode

Lightweight self-contained simulator.db use kiya gaya hai. Multi-threading lock error se bachne ke liye WAL Mode (PRAGMA journal_mode=WAL;) aur timeout=30.0 enable kiya gaya hai.

🔒 5. Security & Admin Authentication

A. PBKDF2-HMAC-SHA256 Password Encryption

Passwords ko plain text me store nahi kiya jata. Har password 16-byte cryptographic random salt aur 100,000 hashing iterations ke sath secure rehta hai.

B. Role-Based Token Authorization & OTP Recovery

Backend HMAC-SHA256 se signed 7-day Bearer Token verify karta hai. Forgot Password flow me 10-minute expiry ke sath 6-digit OTP generate hota hai.

💡 6. Top Technical Interview Q&A (Hinglish)

Q1: LocalStorage aur Database dono kyu use kiye?

Ans: Candidate ke liye instant speed aur zero-friction experience ke liye LocalStorage me 25-Test FIFO history rakhi gayi hai, jabki platform owner ke global metrics aur aggregated analytics ke liye backend SQLite database sync kiya gaya hai.

Q2: Password hashing ke liye PBKDF2 kyu use kiya?

Ans: Standard SHA-256 bahut fast hota hai jisse brute force attack ho sakta hai. PBKDF2 100,000 iterations aur random salt ke sath GPU attacks ko completely eliminate kar deta hai.

Q3: SQLite me database lock issue kaise solve kiya?

Ans: WAL Mode (Write-Ahead Logging) enable karke solve kiya jisme concurrent readers aur writers ek doosre ko block nahi karte.

Q4: WebCam tracking bina heavy TensorFlow library ke kaise kiya?

Ans: Heavy 60MB library ke bajaye Canvas Optical Center-of-Mass skin ratio heuristic use kiya, jisse CPU usage sirf 2% rehta hai aur page fast load hota hai.
